# StockIA Predict — Mockups v1

Incluye cinco mockups conceptuales de escritorio y un diagrama de flujo funcional.

## Pantallas
1. Resumen de demanda
2. Datos y validación
3. Segmentación de demanda
4. Pronóstico por producto
5. Alertas de volumen inusual

## Alcance
Los mockups son ilustrativos y no representan un MVP implementado. La fuente experimental es UCI Online Retail II (Chen, 2012), CC BY 4.0. Los valores visibles en las pantallas son demostrativos. StockIA pronostica ventas observadas por producto y semana; no calcula stock ni cantidades automáticas de reposición porque el dataset no contiene inventario ni datos de proveedores.
